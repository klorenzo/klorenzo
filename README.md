# Hi, I'm Kevin 👋

I'm a Sr. Software Engineer and I've been building software professionally since 2013. These days a lot of my work
is AI engineering on AWS, and I also have experience managing engineering teams.

## What I do with AI

- Build agents that automate multi-step workflows by calling tools and APIs.
- Build a RAG assistant that answers questions from internal documentation.
- Use LLMs for data processing and report generation.
- Run machine learning on Amazon SageMaker for forecasting, classification and anomaly detection, and work
  with embeddings for search and with fine-tuning.
- Got my team using Claude Code and GitHub Copilot day to day.

## The rest of my stack

Behind the AI work there's a regular engineering background. On the backend that's Java and Spring, plus
Node.js, TypeScript and Python. On the frontend it's React, Angular and Vue. On AWS I use Lambda, API Gateway, ECS,
EKS, S3, SQS, SNS and EventBridge, with Terraform and GitHub Actions. Earlier on I built AEM sites, mobile apps
for Android and iOS (and later Flutter), and payments and checkout APIs.
